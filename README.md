## stuff i've built

**SOPAN** - career platform that maps your skills, finds the gaps, and shows how to close them. built for smart india hackathon 2026. led the team, reached the finals.
[Live](https://sopan-career.onrender.com)
python, postgresql, sql

**AIVOA** - ai root cause analysis for pharma plants. reads deviation reports, checks past cases, explains what went wrong and why.
[Code](https://github.com/priyanshu-pgb/aivoa-rca) and [Live demo](https://aivoa-rca-omega.vercel.app)
python, fastapi, sqlite, rag

**X-Sentiment BTC Predictor** - fed 70,585 tweets and bitcoin prices to a model to guess the next move. sharpe 1.76. it did not beat the simple baseline on accuracy, and i published that too. not financial advice.
[Code](https://github.com/priyanshu-pgb/cwt-x-sentiment)
python, sqlite, gradient boosting

**Arogya Drishti** - health screening that runs on the phone itself. no internet needed.
python, opencv, mobilenetv3
